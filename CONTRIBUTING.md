# Contributing

## Development Setup

```bash
npm install
npm test
```

## Submitting Changes

1. Fork the repository.
2. Create a branch, such as `feature/my-change`.
3. Commit using Conventional Commits, for example `feat: add amazing feature`.
4. Run the tests with `npm test`.
5. Submit a pull request.

## Code Style

- Use 2 spaces for indentation.
- Use semicolons at the end of statements.
